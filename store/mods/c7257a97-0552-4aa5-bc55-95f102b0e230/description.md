# Chest Peek

Point at a chest, dresser, piggy bank, safe, defender's forge or void vault to see its contents in a small panel. Locked chests show nothing, and the panel hides while a chest is open.

The mod is free software under the **GNU GPL version 3** (see the License tab). Its C# source code is in the `mods/chestpeek` folder of the [Bunny-Loader-CSharp-Mods](https://github.com/JonataOliveiraa/Bunny-Loader-CSharp-Mods) repository.
