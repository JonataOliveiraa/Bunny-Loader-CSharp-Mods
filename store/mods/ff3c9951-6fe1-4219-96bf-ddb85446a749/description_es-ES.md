# 🌙 Mount and Journey FM

**🐉 Monturas extraordinarias · ✨ Nuevas formas · 🌌 Un viaje fuera de lo común**

---

> **Port para Terraria Mobile** · Bunny Loader · Hecho con el permiso del autor original (Qz)

**Tu próxima aventura comienza cuando encuentras una nueva forma de explorar el mundo.**

**Mount and Journey FM** lleva a **Terraria Mobile** el mod *Mount and Journey*, creado por **Qz**, con los scripts adaptados para **Bunny Loader**.

## ✨ Características

- 🐉 **Monturas** para todo tipo de terreno: raptores, arañas, dragones, wyverns, las naves de los pilares y mucho más.
- 🦊 **Transformaciones** en animales y criaturas.
- 🧿 **Accesorios** que mejoran cualquier montura y se pueden combinar.
- ⚡ **Orbe meteorológico**, que despierta al Dragón mítico y desata rayos.
- 🎮 **Controles táctiles** para embestidas, teletransporte, apuntado y descargas.

## 🚀 Cómo empezar

1. Consigue un objeto de montura o de transformación mediante receta, botín, pesca o el Extractinator.
2. Usa el objeto para invocar la montura o transformarte.
3. Equipa accesorios para ganar velocidad, defensa, vuelo y embestida.
4. Activa los botones táctiles en el editor de controles del juego, para las monturas con acciones especiales.
