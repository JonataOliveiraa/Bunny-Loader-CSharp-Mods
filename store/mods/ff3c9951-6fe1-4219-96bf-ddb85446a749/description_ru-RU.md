# 🌙 Mount and Journey FM

**🐉 Необычные скакуны · ✨ Новые облики · 🌌 Путешествие за гранью обыденного**

---

> **Порт для Terraria Mobile** · Bunny Loader · Сделан с разрешения оригинального автора (Qz)

**Ваше следующее приключение начнётся, когда вы найдёте новый способ исследовать мир.**

**Mount and Journey FM** переносит на **Terraria Mobile** мод *Mount and Journey* авторства **Qz**; скрипты адаптированы для **Bunny Loader**.

## ✨ Особенности

- 🐉 **Скакуны** для любой местности: рапторы, пауки, драконы, виверны, корабли столпов и многое другое.
- 🦊 **Превращения** в животных и существ.
- 🧿 **Аксессуары**, которые улучшают любого скакуна и сочетаются друг с другом.
- ⚡ **Сфера погоды**, пробуждающая Мифического дракона и высвобождающая молнии.
- 🎮 **Сенсорное управление** для рывков, телепортации, прицеливания и разрядов.

## 🚀 С чего начать

1. Получите предмет скакуна или превращения: по рецепту, с добычи, рыбалкой или через Extractinator.
2. Используйте предмет, чтобы призвать скакуна или превратиться.
3. Наденьте аксессуары, чтобы повысить скорость, защиту, полёт и силу рывка.
4. Включите сенсорные кнопки в редакторе управления игры для скакунов с особыми действиями.
