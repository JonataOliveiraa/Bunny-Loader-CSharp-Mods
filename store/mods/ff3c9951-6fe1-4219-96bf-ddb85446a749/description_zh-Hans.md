# 🌙 Mount and Journey FM

**🐉 非凡坐骑 · ✨ 全新形态 · 🌌 超越寻常的旅程**

---

> **Terraria Mobile 移植版** · Bunny Loader · 已获得原作者（Qz）许可

**当你找到探索世界的新方式，下一场冒险就此开始。**

**Mount and Journey FM** 将 **Qz** 制作的模组 *Mount and Journey* 带到 **Terraria Mobile**，脚本已针对 **Bunny Loader** 做了适配。

## ✨ 特色

- 🐉 **坐骑**：适用于各种地形，包括迅猛龙、蜘蛛、巨龙、双足飞龙、天界柱飞船等等。
- 🦊 **变身**：化身为各种动物和生物。
- 🧿 **饰品**：强化任意坐骑，并且可以相互合成。
- ⚡ **气象球**：唤醒神话巨龙，释放闪电。
- 🎮 **触控操作**：支持冲刺、传送、瞄准和释放能量。

## 🚀 快速上手

1. 通过配方、掉落、钓鱼或 Extractinator 获得坐骑或变身物品。
2. 使用物品来召唤坐骑或变身。
3. 装备饰品来提升速度、防御、飞行和冲刺能力。
4. 对于有特殊操作的坐骑，请在游戏的控制编辑器中启用触控按钮。
