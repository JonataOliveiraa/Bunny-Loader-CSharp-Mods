# Flat Seed

โลกที่แบนจนวิ่งได้สบายโดยไม่ต้องกลัวสะดุดหรือตกหลุม! พื้นผิวจะเรียบสนิท ส่วนอย่างอื่นจะถูกสร้างตามปกติ
ทั้งถ้ำ ไบโอม แร่ คุกใต้ดิน วิหาร เกาะลอยฟ้า และนรก

## วิธีใช้

นี่คือ**ซีดลับ** ตอนสร้างโลกใหม่ ให้พิมพ์รหัสใดรหัสหนึ่งต่อไปนี้ในช่องซีด:

| ภาษา | รหัส |
|---|---|
| English | `flat`, `flat world`, `superflat` |
| Português | `plano`, `mundo plano`, `superplano` |
| Español | `plano`, `mundo plano` |
| Français | `plat`, `monde plat` |
| Deutsch | `flach`, `flache Welt` |
| Italiano | `piatto`, `mondo piatto` |
| Polski | `płaski`, `płaski świat` |
| Русский | `плоский`, `плоский мир` |
| 中文 | `平坦`, `平坦世界`, `平面世界` |
| 日本語 | `平ら`, `平らな世界` |
| 한국어 | `평평`, `평평한 세계` |
| Tiếng Việt | `phẳng`, `thế giới phẳng` |
| ไทย | `แบน`, `โลกแบน` |

ซีดนี้ยังแสดงอยู่ในรายการซีดลับของเกม จึงใช้ร่วมกับซีดลับอื่นได้ เฉพาะโลกใหม่ที่สร้างด้วยซีดนี้เท่านั้นที่จะแบน
โลกอื่น ๆ ของคุณจะไม่ถูกเปลี่ยนแปลง

## การสร้างโลก

ระหว่างสร้างโลกจะมีขั้นตอนใหม่ **กำลังปรับโลกให้เรียบ...** (ข้อความในเกมจะแสดงตามภาษาของเกม):
ปรับพื้นผิวให้เรียบ ทำทางลาดลงชายหาดให้นุ่มนวล และคงชั้นดินไว้ด้านบน จะไม่มีเนินเขา อุโมงค์
และทะเลสาบบนพื้นผิว เกาะลอยฟ้าจะถูกเก็บไว้ครบทั้งเกาะ รวมถึงทราย

เมื่อใช้ร่วมกับซีดลับ **Mole People** (ไม่มีพื้นผิว) โลกจะไม่ถูกปรับให้เรียบ

## ตัวเลือก

ที่เมนูหลัก: **การตั้งค่า > การตั้งค่าม็อด > Flat Seed**

| ตัวเลือก | ทำอะไร |
|---|---|
| ความสูงของพื้นผิว | ตำแหน่งของพื้นราบ เป็นเปอร์เซ็นต์ของความสูงโลก (ค่าเริ่มต้น 20%) |
| เติมรอยแยก | เติมหลุมและรอยแยกที่เปิดอยู่บนพื้นผิวด้วย |
| ทางลาดชายหาด | ทางลาดนุ่มนวลจากพื้นราบลงสู่มหาสมุทร |

## หมายเหตุ

เมื่อใช้กับม็อดเนื้อหา หน้าจออาจดูเหมือนค้างไปครู่หนึ่งระหว่างสร้างโลก แต่โลกยังสร้างอยู่ แค่รอสักครู่
